# 🦝 Ветеринар-аналитик

Днём — ветеринарная аналитика и эпиднадзор, ночью — CAN-шина и ISO-TP.
Строю открытую экосистему ветеринарных инструментов: 20+ проектов, от метеопрогнозов до фармакодинамики в браузере.

## 🐄 Экосистема

- **[VetHub](https://github.com/shray77/vet-hub)** — ситуационный центр: метео + хитмап болезней + ВПГП + TimesFM в одном окне
- **[ВЕТМЕТО](https://github.com/shray77/vet-meteo)** — метеопрогноз для ветеринаров: THI/BRD/паразиты/АЧС, 16 станций Ростовской обл., ансамбль ECMWF
- **[VetTools](https://github.com/shray77/vettools)** — офлайн-инструмент ветврача: SOAP, выписка, протоколы, калькуляторы — один HTML без сети
- **[VetVoice](https://github.com/shray77/vetvoice)** — справочник и калькулятор дозировок с голосовым управлением (Flutter + Vosk)
- **[VetInSilico](https://github.com/shray77/vet-insilico)** — in silico drug repurposing для ветеринарных патогенов
- **[VetПетри](https://github.com/shray77/vetpetri)** — фармакодинамика в браузере: Моно/Бараньи, Хилл/Emax, time-kill, окно селекции
- **[БиоБарьер](https://github.com/shray77/biobarrier-site)** — скоринг биобезопасности хозяйства: анкета 0–100, бенчмарки Biocheck.UGent
- **[ФЭКРТ](https://github.com/shray77/vetfecrt-site)** — калькулятор резистентности к антигельминтикам (WAAVP-2023)

…и ещё дюжина: LLM-дайджесты, TimesFM-прогноз ВПГП, предрасположенности пород, болевые шкалы.
